# TRACE

Replaceable evidence observer and reconstruction substrate for AI-accelerated development workflows.

## Repository role

TRACE records and reconstructs observable execution evidence, completion evidence, human-decision boundaries, PR lifecycle evidence, and loop/reality measurements.

TRACE is **an observer, not a governor**. It does not become promotion authority merely because it records evidence.

## Start here

1. `AGENTS.md` — AI operating boundary and context budget.
2. `CODEX_START.md` — bounded Codex/operator entrypoint.
3. `COMPLETION_PROTOCOL.md` — completion-evidence rules when completion is material.
4. `ULTIMATE_LOOP_OBSERVER.md` — observer relationship to Ultimate Loop.
5. Load `TRACE_BOOTSTRAP.md` or historical/run material only when reconstruction/bootstrap work actually requires it.

## Core rule

```text
OBSERVATION != AUTHORITY
RECORDED != VERIFIED
DEPLOYED != CORRECT
MISSING EVIDENCE != SUCCESS
```

## Context rule

Do not load every root protocol, run, test, and historical artifact by default. Start from the active evidence question and read the narrowest relevant protocol plus targeted run/test evidence.
